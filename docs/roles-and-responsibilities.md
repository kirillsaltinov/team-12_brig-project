***## Роль: Специалист по БД***



***\*\*Основные обязанности:\*\****

* ***Проектирование логической и физической структуры базы данных (разработка ER-диаграмм, нормализация таблиц).***
* ***Написание SQL-скриптов для создания, изменения и удаления объектов БД (DDL-запросы).***
* ***Разработка скриптов для наполнения базы данных тестовыми и реальными данными (DML-запросы).***
